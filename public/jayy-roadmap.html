The order matters

Five Stages

01 / BASICS

Learn how data is stored, cleaned, split and measured before any model sees it.

02 / CORE IDEAS

Understand features, labels, training, loss, optimisation, generalisation and the train/validation/test split.

03 / CLASSICAL ML

Start with simple, explainable models. Then compare them with trees, ensembles and margin-based methods.

04 / UNSUPERVISED

Use clustering, dimensionality reduction and anomaly detection when there is no correct answer column.

05 / DEEP LEARNING

Move into computer vision, language, sequences and generative models after the core ideas feel familiar.

First question

Types of learning

01

Learn from examples that already have the correct answer, such as predicting a price or deciding whether something belongs to a class.

02

Look for useful patterns or groups in data when there are no correct answers provided.

03

Learn from a small set of answered examples together with a much larger set of unanswered examples.

04

Create a learning task from the data itself, such as hiding part of an input and asking the model to predict it.

05

Learn by taking actions, receiving rewards or penalties, and improving decisions over time.

06

Learn the patterns in existing data well enough to create new text, images, audio or other examples.
